# Clickmoji Shop: реестр возможностей

<!-- last_synced_commit: 39e3ff0a2d02791509a3f6deeb4614449d1edf2f -->

Снимок возможностей исходного кода на указанном коммите для сравнения продукта, а не свидетельство проверки работающего развёртывания. Ссылки в таблицах закреплены за этим коммитом. Доступность интеграций зависит от конфигурации; данные и внешний сервис здесь не проверялись. Для планов источником служит [roadmap](https://github.com/GhenovNik/clickmoji-shop/blob/39e3ff0a2d02791509a3f6deeb4614449d1edf2f/docs/roadmap.md#L35-L73).

## Легенда

| Статус    | Значение                                                                         |
| --------- | -------------------------------------------------------------------------------- |
| available | Возможность реализована в коде для указанного сценария.                          |
| partial   | Реализована с существенными ограничениями, зависимостями или неполным покрытием. |
| prototype | Учебная или сырая реализация; не утверждается производственная готовность.       |
| planned   | Намечено в roadmap; соответствующая полная возможность не подтверждена кодом.    |
| missing   | Не подтверждено как реализованное или запланированное.                           |

## Индивидуальность

Главная идея — визуально индивидуализировать каждый товар, бренд, вариант и личный товар. Это замысел, а не гарантия уникальной картинки для каждой позиции: данные допускают общий Unicode, пустые необязательные URL и fallback.
