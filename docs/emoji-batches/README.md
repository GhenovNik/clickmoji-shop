# Пачки emoji для каталога (AGE-1465)

Оператор генерирует картинки бесплатно по подписке Gemini (сетка 3×3), приложение потом режет,
нормализует и привязывает их к товарам.

## Файлы

- `catalog-snapshot-2026-10-30.json` — общий каталог на 2026-10-30 (только названия), из
  резервной копии продовой БД `backups/before-ai-usage-counters.dump`.
- `candidates.json` — что добавить: распространённые продукты и бытовые товары по деревьям
  категорий Open Food Facts / USDA FoodData Central и крупных магазинов, без того, что уже есть в
  каталоге, и без синонимов. `redo` — существующие товары без картинки, у которых сейчас 📦.
- `batches/batch-NNN.md` — пачка из 9 товаров: таблица ячеек и готовый промпт.
- `manifest.json` — «пачка → ячейка → товар», вход для импорта.

Пересобрать после правки `candidates.json`: `npx tsx scripts/emoji-batches.ts`. Скрипт падает,
если товар уже есть в каталоге, повторяется или указан в несуществующей категории.

## Как генерировать

1. Для каждой пачки — **новый чат** в Gemini (иначе модель дорабатывает прошлую картинку).
2. По возможности приложить 2–3 emoji каталога отдельными картинками как образец стиля.
3. Вставить промпт из `batch-NNN.md`.
4. Сохранить результат как `~/Downloads/clickmoji-batches/batch-NNN.png` (номер пачки — в имени
   файла). Ячейки читаются слева направо, сверху вниз, как в таблице пачки.

5. **Если на картинке есть надписи** (упаковки: кефир, сливки, тортилья…) — в **том же чате**
   отправить английский промпт из того же файла и сохранить ответ как `batch-NNN-en.png`. Gemini
   правит свою же картинку, поэтому рисунки совпадают и меняются только надписи. Приложение
   хранит английский вариант отдельно (`products.imageUrlEn`) и покажет его в английском
   интерфейсе; картинки без текста общие для обоих языков.

Если ячейка не удалась, достаточно перегенерировать пачку целиком или отдать одиночную картинку
`batch-NNN-C.png`, где C — номер ячейки.

## Импорт в приложение

Скрипт режет сетки, нормализует картинки (WebP 256 с прозрачностью) и привязывает их к товарам
каталога. Без `--apply` он ничего не пишет: в `~/Downloads/clickmoji-batches/preview/` появляются
картинки и `preview.html` — картинка на светлом и тёмном фоне, ru и en, и что будет сделано
(привязать к существующему товару / создать товар / только библиотека).

```bash
npx tsx scripts/emoji-import.ts --batch 001,002,003
```

С `DATABASE_URL` предпросмотр сверяется с настоящим каталогом и показывает, какие ячейки уже
загружены. Запись (оператор, после миграции из `docs/emoji-library-migration.md`):

```bash
DATABASE_URL='<прямой URL>' UPLOADTHING_TOKEN='<токен>' npx tsx scripts/emoji-import.ts --batch 001,002,003 --apply
```

- Каждая ячейка — запись библиотеки с ссылкой `batch-NNN#C` (английская — `batch-NNN#C:en`).
  Повторный запуск ничего не загружает заново и только перепривязывает товары.
- Товар ищется по названию (регистр и «ё» не важны) среди общего каталога; если нет — создаётся в
  категории из манифеста с emoji категории.
- Плохую ячейку можно заменить одиночной картинкой `batch-NNN-C.png` (и `batch-NNN-C-en.png`) и
  запустить импорт этой пачки ещё раз. Старая картинка останется в хранилище; замена через
  повторную загрузку — с `--apply` по той же ссылке пока не перезаливается (удалите запись
  библиотеки в админке или напишите мне).
